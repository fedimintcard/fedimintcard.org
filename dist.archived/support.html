Common answers

  • The home page and its film show how a card is loaded, how it pays at a till and what the federation does.
  • Risks to know covers what can go wrong while the card is a prototype.
  • The source repository has the applet, the host code and the till, with their documents.

Email

Write to hi@fedimintcard.org for help or with anything else. Say which card, reader or phone you use and what happened. Leave out seed phrases, PINs and card secrets.

Questions and bugs

Report a bug or ask a question as a GitHub issue, where the answer helps the next person too.

Security, conduct and privacy

  • Report a security problem privately through a GitHub security advisory or to hi@fedimintcard.org, as the security policy asks.
  • Report a code of conduct problem to hi@fedimintcard.org. The code of conduct explains how reports are handled.
  • Send privacy requests to hi@fedimintcard.org. The privacy policy explains what we hold.

Fedimint Card is an independent open source project built on the Fedimint protocol, released under the MIT License. Contact: hi@fedimintcard.org
